Receiver → ESC mappings

Edit each mapping below, then Apply all. Inputs may be shared; each output must be unique. Losing any input disarms all outputs.

01

Throttle envelope

Start low. Verify neutral before arming.

Scale uses the full stick travel within your limit. Clamp keeps the original response, then caps it. A percentage limits the signal command; it does not measure speed or power.

02

Pin mapping

Use GPIO numbers, not physical header positions.

Pico default: GP4 → GP5. ESP32 default: GPIO27 → GPIO25. The board validates its pin allowlist.

03

Receiver calibration

Read the pulse at each stick endpoint and neutral.

04

ESC calibration

Use the stop pulse specified by your ESC.

Bidirectional default: 1000 / 1500 / 2000 µs. Signal loss disarms and sends the configured neutral. Configure and test your receiver's radio-loss failsafe too.

Ready at neutral?

Hold every mapped input at stop for 1 second, then arm all.

Settings shown are defaults until read from a board. Disconnection is not a confirmed stop.

Receiver → ESC mappings

Edit each mapping below, then Apply all. Inputs may be shared; each output must be unique. Losing any input stops all outputs.

01

Throttle envelope

Start low. Control enables after one second at neutral.

Scale uses the full stick travel within your limit. Clamp keeps the original response, then caps it. A percentage limits the signal command; it does not measure speed or power.

02

Pin mapping

Use GPIO numbers, not physical header positions.

Pico default: GP4 → GP5. ESP32 default: GPIO27 → GPIO25. The board validates its pin allowlist.

Board layouts, suggested pins & 5 V input resistors

Cyan = selected receiver input · lime = selected ESC output · grey = reserved by this project · orange = input-only. Other GPIOs still require board and firmware checks.

All shown GPIOs use 3.3 V logic. Do not connect a 5 V receiver signal directly.

Receiver SIGNAL ── 4.7 kΩ ──┬── RX GPIO
                           │
                         6.8 kΩ

Common GND ────────────────┴── board GND

Use 1% resistors for a confirmed 5 V pulse: about 2.96 V at the GPIO. An already 3.3 V signal becomes about 1.95 V and may not register. A divider does not isolate an unpowered MCU. Prefer SN74LVC1G17 at 3.3 V for mixed power sequencing. Add a separate 10 kΩ pulldown on each ESC output; an optional 100–220 Ω output series resistor reduces ringing and does not level-shift voltage.

03

Receiver calibration

Read the pulse at each stick endpoint and neutral.

04

ESC calibration

Use the stop pulse specified by your ESC.

Bidirectional default: 1000 / 1500 / 2000 µs. Signal loss stops all outputs at the configured neutral. Configure and test your receiver's radio-loss failsafe too.

Automatic receiver control

Hold every mapped input at neutral for one second. Signal loss stops all outputs; return to neutral for one second to resume.
